# Workout Calendar

Personal workout log. Open it at https://orbelloelias-del.github.io/workout/

- `index.html` is the whole site.
- Your workouts are saved to your own Firebase database (project `workout-log-3db1e`) after you tap **Sign in with Google** once on each device. Only your Google account can read or write them.
- `data/workout-data.json` is the snapshot from 7.10.26 that was moved into the database on first sign-in. It is no longer updated.
